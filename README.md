# ChatDM prototype

This is a mobile-responsive, Discord-inspired front-end prototype.

## Run
Open `index.html` in a browser, or upload the folder to a static hosting provider.

## Included
- Responsive dark chat interface
- Server and channel navigation
- Local demo message sending
- Demo create-server and create-channel dialogs
- Mobile sidebar drawer

## Important limitations
This is a front-end prototype. Messages are not shared between users and are not persisted.
Google/email authentication, database-backed servers, private DMs, uploads, notifications,
permissions and WebRTC voice/video require a backend such as Supabase and additional setup.
